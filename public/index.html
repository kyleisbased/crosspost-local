YouTube setup

The app owner creates one Google Cloud Desktop OAuth client and enables YouTube Data API v3. Import the downloaded client JSON here. Each friend then signs in with their own Google account.

Setup instructions

Never import or share your personal token files. Replacing these app settings requires reconnecting YouTube profiles.

About account connections

YouTube uses Google sign-in in your normal browser and verifies the channel automatically. Instagram and TikTok use separate browser windows; check the account name before saving.

Browser uploads are experimental and still need signed-in testing. Login or verification prompts may require your help.

Sessions stay on this computer. Do not share the app's data folder.

Updates

Open Update-Windows.cmd or Update-Mac.command next to the app. The updater downloads the newest tested app code and keeps your videos, profiles, and schedules. Finish any current upload first.

In Codex, open the app folder and say: Update Crosspost using its included updater.
